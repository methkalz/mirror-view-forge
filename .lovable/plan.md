

# إضافة تأثير ارتداد عند الإطلاق

## التغيير

### `src/game/engine.ts`
عند الإطلاق (سطر ~592)، إضافة دفعة سرعة عكسية لاتجاه اللاعب:
```
p.velocity.x += p.facingRight ? -60 : 60;
```
هذا يعطي ارتداداً خفيفاً طبيعياً يتلاشى تلقائياً بفضل نظام الاحتكاك الموجود.
