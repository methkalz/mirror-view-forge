

# تكبير الشخصية + نظام تدرج تهديدات سينمائي

## 1. تكبير الشخصية
**ملف:** `src/game/renderer.ts` + `src/game/engine.ts`
- رفع مقياس الرسم من `1.3` → `1.6`
- رفع `PLAYER_RADIUS` من `18` → `22`

## 2. فترة أمان أولية (3 ثوانٍ بدون سقوط)
**ملف:** `src/game/engine.ts`
- تغيير `g.spawnTimer` في `resetGame` من `2.5` → `3.5` (3 ثوانٍ أمان + تأخير أول سقوط)
- إضافة شرط في spawn: لا يُنشأ أي hazard إذا `g.elapsed < 3`

## 3. فصل أنواع التهديدات زمنياً
حالياً missiles تُخلط مع shrapnel من البداية (سطر 591). التعديل:
- **0-3 ثوانٍ**: لا شيء (أمان)
- **3 ثوانٍ**: تحذير سينمائي "شظايا!" ثم تبدأ شظايا فقط
- **15-25 ثانية** (عشوائي): تحذير سينمائي "صواريخ!" ثم تُضاف صواريخ
- **الباقي** (clusters عند 90ث، drones عند 90ث، boss عند 240ث): يبقى كما هو مع التحذيرات الموجودة

تعديل سطر 591 ليكون:
```
const types: HazardType[] = ['shrapnel'];
if (g.elapsed >= missileStartTime) types.push('missile');
if (g.elapsed >= 90) types.push('cluster');
```

## 4. نظام تحذير سينمائي جديد (وسط الشاشة + blur + slow-mo)
هذا هو التغيير الأكبر. عند كل تهديد جديد يظهر لأول مرة:

### المنطق (`engine.ts`):
- إضافة حقل `cinematicWarning` في `GameData`: `{ text, subText, color, timer, duration }`
- عند trigger أي waveEvent جديد يخص نوع تهديد (شظايا/صواريخ/clusters/drones/boss):
  - تعيين `g.cinematicWarning` بالنص المناسب، مدة `1.5` ثانية
  - فرض `g.slowMoFactor = 0.1` طوال مدة التحذير
- في كل frame: إنقاص `cinematicWarning.timer`، وعند انتهائه إعادة `slowMoFactor` للطبيعي

### الرسم (`renderer.ts`):
- دالة جديدة `renderCinematicWarning()`:
  - **خلفية blur**: مستطيل شبه شفاف أسود يغطي كامل الشاشة (`rgba(0,0,0,0.5)`)
  - **نص كبير** في منتصف الشاشة بالضبط (خط 28-32px، bold)
  - **نص فرعي** أسفله (خط 14px)
  - **تأثير fade-in/fade-out** حسب الـ timer
  - **حدود متوهجة** بلون التحذير
