

# تحسين أنيميشن شاشة تلميح الصوت

## الوضع الحالي
النص `"🔊 فعّل الصوت لتجربة أفضل"` يظهر بأنيميشن بسيط جداً (scale 0.95→1 + fade) — لا يلفت الانتباه بشكل كافٍ.

## التحسينات — `src/components/NameEntry.tsx`

### 1. أنيميشن ظهور متدرج للكلمات (Staggered reveal)
- بدل ظهور الجملة كاملة دفعة واحدة، تظهر كلمة تلو الأخرى بفاصل ~150ms
- كل كلمة تظهر بـ `opacity: 0→1` + `translateY(8px→0)` + `blur(4px→0)`
- تأثير "typewriter أنيق" بدون مؤشر كتابة

### 2. أيقونة 🔊 بنبض خفيف
- الأيقونة تظهر أولاً وحدها مع نبض حجمي لطيف (`scale 1→1.1→1`)
- ثم تبدأ الكلمات بالظهور تحتها

### 3. توهج خفيف خلف النص
- `text-shadow` ذهبي خفيف (`rgba(251,191,36,0.15)`) يظهر تدريجياً مع اكتمال الجملة

### 4. Fade out محسّن
- عند الخروج: الكلمات تختفي بترتيب عكسي سريع (~80ms لكل كلمة) ثم تتلاشى الأيقونة

### التنفيذ
- تقسيم النص لمصفوفة كلمات + عرض كل كلمة بـ `span` مع `animation-delay` مختلف
- إضافة keyframes: `wordReveal`, `iconPulse`, `staggeredFadeOut`
- تعديل توقيت `hintFading` ليتناسب (يبدأ عند 2400ms بدل 2600ms لإتاحة وقت للـ staggered exit)
