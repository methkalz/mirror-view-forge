

# إضافة أنواع أعداء جديدة + عناصر حماية (نار، غاز، كمامة، طفاية)

## الفكرة العامة

إضافة نظام **مخاطر بيئية** جديد: طائرات تلقي نيران وغاز على الأرض، مع عناصر حماية (كمامة + طفاية) كـ power-ups جديدة.

---

## 1. أنواع الطائرات الجديدة

### طائرة النيران (Incendiary Drone) — `tier: 'incendiary'`
- **الظهور**: بعد **160 ثانية** (بين Tracker و Bomber)
- **السلوك**: تطير فوق اللاعب وتلقي قنبلة حارقة على نقطة محددة
- **النتيجة**: بركة نار على الأرض تبقى **4-6 ثوانٍ**، تسبب **3 ضرر/ثانية** عند الوقوف عليها
- **الشكل**: طائرة حمراء/برتقالية بخزان وقود سفلي متوهج
- **HP**: 2 (رصاصتان)

### طائرة الغاز (Chemical Drone) — `tier: 'chemical'`
- **الظهور**: بعد **200 ثانية** (مع القاذفات)
- **السلوك**: تطير ببطء وتلقي عبوة غاز تنشر سحابة خضراء سامة
- **النتيجة**: سحابة غاز على الأرض تبقى **5-8 ثوانٍ**، تسبب **2 ضرر/ثانية** + تبطئ اللاعب 50%
- **الشكل**: طائرة خضراء داكنة بعلامة ☣ وخزان أخضر سفلي
- **HP**: 2

---

## 2. المخاطر الأرضية الجديدة

### بركة النار (FirePool)
```text
- pos, size (نصف قطر ~40-60px)
- life: 4-6s
- damagePerSec: 3
- يمكن إطفاؤها بطفاية الحريق (تختفي فوراً)
- بصرياً: ألسنة لهب متراقصة برتقالية/حمراء + توهج أرضي
```

### سحابة الغاز (GasCloud)
```text
- pos, size (نصف قطر ~50-70px)
- life: 5-8s
- damagePerSec: 2
- تبطئ حركة اللاعب 50% داخلها
- الكمامة تحمي منها تماماً
- بصرياً: دائرة خضراء شفافة متموجة مع جزيئات صاعدة
```

---

## 3. عناصر الحماية الجديدة (Power-Ups)

### كمامة الغاز (Gas Mask) — `type: 'gasmask'`
- **الظهور**: تبدأ بالسقوط من المظلات بعد ثانية **195** (قبل ظهور طائرات الغاز بـ 5 ثوانٍ)
- **المدة**: **15 ثانية** بعد الالتقاط
- **التأثير**: حصانة كاملة من الغاز (لا ضرر + لا تباطؤ)
- **المؤشر**: أيقونة كمامة خضراء في زاوية الـ HUD + شريط مدة متناقص
- **التصميم**: صندوق أخضر بأيقونة كمامة عسكرية

### طفاية الحريق (Fire Extinguisher) — `type: 'extinguisher'`
- **الظهور**: تبدأ بالسقوط بعد ثانية **155** (قبل ظهور طائرات النيران بـ 5 ثوانٍ)
- **التأثير**: فوري — تطفئ **جميع برك النار** الموجودة حالياً + حصانة من النار لمدة **8 ثوانٍ**
- **المؤشر**: أيقونة طفاية حمراء في HUD + شريط مدة
- **التصميم**: صندوق أحمر بأيقونة طفاية

---

## 4. مؤشرات الـ HUD

```text
┌─────────────────────────────┐
│  ❤ 80/100    🔫 ×12        │
│                             │
│  [🔥 ██████░░ 5s]  ← طفاية │
│  [☣ ████████░ 12s] ← كمامة │
│                             │
└─────────────────────────────┘
```
- أيقونات صغيرة على يسار الشاشة تحت الـ HP
- شريط مدة ملون يتناقص (أحمر للطفاية، أخضر للكمامة)
- تظهر فقط عندما يكون التأثير نشطاً

---

## 5. الجدول الزمني المحدث

| الثانية | الحدث |
|---------|-------|
| 155 | أول طفاية حريق تسقط (تحضير) |
| 160 | ⚠ تحذير + ظهور طائرات النيران |
| 195 | أول كمامة غاز تسقط (تحضير) |
| 200 | ⚠ تحذير + ظهور طائرات الغاز |

---

## 6. سيناريوهات اللعب

1. **اللاعب بدون حماية + نار**: يتلقى ضرراً مستمراً — يجب الابتعاد فوراً
2. **اللاعب + طفاية + نار**: محصن، يمكنه المرور فوق النار بأمان
3. **اللاعب بدون كمامة + غاز**: ضرر + تباطؤ — خطير جداً مع صواريخ
4. **اللاعب + كمامة + غاز**: يمر بأمان تام
5. **طفاية تُلتقط**: كل النيران الحالية تنطفئ + حصانة مؤقتة
6. **كمامة تنتهي مدتها**: يعود اللاعب لحالته الطبيعية

## التفاصيل التقنية

### `src/game/types.ts`
- إضافة `'incendiary' | 'chemical'` إلى `DroneTier`
- إضافة `'gasmask' | 'extinguisher'` إلى `PowerUpType`
- إضافة `interface FirePool { pos, size, life, maxLife }`
- إضافة `interface GasCloud { pos, size, life, maxLife }`
- إضافة لـ `Player`: `gasMaskTimer`, `extinguisherTimer`
- إضافة لـ `GameData`: `firePools[]`, `gasClouds[]`

### `src/game/engine.ts`
- دوال `spawnIncendiaryDrone()` و `spawnChemicalDrone()`
- منطق قصف النار/الغاز في update loop
- تحديث `damagePlayer` ليأخذ بالاعتبار الحماية
- تصادم اللاعب مع FirePool/GasCloud + فحص الحماية
- إضافة waveEvents للتحذيرات الجديدة
- إسقاط تحضيري للكمامة/الطفاية قبل ظهور التهديد

### `src/game/renderer.ts`
- رسم FirePool: ألسنة لهب متحركة + توهج أرضي برتقالي
- رسم GasCloud: دائرة خضراء شفافة مع جزيئات سامة صاعدة
- رسم الطائرتين الجديدتين بتصميم مميز
- HUD: مؤشرات الكمامة والطفاية مع شريط المدة
- تصميم صناديق الـ power-up (أخضر للكمامة، أحمر للطفاية)

### الملفات المتأثرة
1. **`src/game/types.ts`** — أنواع جديدة + حقول
2. **`src/game/engine.ts`** — منطق الطائرات + المخاطر + الحماية
3. **`src/game/renderer.ts`** — رسم كل شيء جديد
