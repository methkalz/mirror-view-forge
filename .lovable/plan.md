

# تحسين شاشة البداية والزر — تصميم سينمائي متقدم

## التحسينات المطلوبة

### 1. الزر — "ابدأ المعركة"
- إزالة تصميم clip-path/SVG الحالي (يبدو مسطحاً وغير مؤثر)
- تصميم جديد: زر عريض بزوايا مشطوفة (beveled) مع:
  - خلفية gradient أحمر عميق مع طبقة noise خفيفة
  - حدود مزدوجة: خارجية حمراء متوهجة + داخلية شفافة
  - تأثير "energy pulse" — توهج أحمر ينبض من المركز للخارج
  - عند الضغط: flash أبيض سريع + scale down
  - نص بخط Tajawal عريض بدون letter-spacing مع glow أحمر ناعم
  - أيقونة سيوف متقاطعة (⚔) بجانب النص
  - عند عدم إدخال اسم: الزر معتم وبدون تأثيرات

### 2. حقل الإدخال
- تحويل الحدود لتصميم مشطوف مطابق للزر (بدل borderRadius دائري)
- إضافة تأثير focus: توهج أحمر خفيف على الحدود
- أيقونة مستخدم شبحية داخل الحقل (placeholder icon)

### 3. البطاقة الزجاجية
- زيادة عمق التأثير: blur أقوى (32px) مع حدود أكثر وضوحاً
- إضافة خطوط زاوية زخرفية (corner brackets) بأسلوب HUD
- تحسين التوهج الداخلي العلوي

### 4. العنوان والعنوان الفرعي
- إضافة تأثير وميض خفيف (subtle flicker) للعنوان الفرعي
- تحسين حجم ومسافات العناصر

### 5. اسم المطور
- إضافة خط فاصل رفيع قبل اسم المطور
- تحسين التباعد
