

# تحسين UI/UX لشرائح تعليم الأزرار — تصميم Spotlight احترافي

## المشاكل الحالية
1. **الزر المضاء مغطى بالتعتيم** — الطبقة السوداء `rgba(0,0,0,0.75)` تغطي كل شيء بما فيه الزر، والـ `scale(1.15)` وحده لا يكفي لإبرازه
2. **البطاقة الزجاجية في المنتصف قد تحجب الأزرار** — لا يوجد حساب ديناميكي للموقع
3. **الأيقونات بسيطة** (◀ ▶ 🎯 🌀) — تحتاج رسوم توضيحية أنيقة SVG
4. **السهم ▼ بسيط** — مجرد نص ثابت بدون ربط بصري واضح

## الحل — ملف واحد: `src/components/SkyfallGame.tsx`

### 1. تقنية Spotlight Cutout (القطع الضوئي)
بدل التعتيم المسطح، استخدام `box-shadow` ضخم على عنصر شفاف بحجم وموقع الزر المضاء:

```text
┌─────────────────────────┐
│  ████████████████████████│  ← تعتيم 
│  ████████████████████████│
│  ████┌──────────┐███████│
│  ████│  شرح عربي │███████│  ← بطاقة زجاجية (أعلى الزر)
│  ████│  + أيقونة │███████│
│  ████└──────────┘███████│
│  █████████▼██████████████│  ← خط ربط مضيء
│  ████████████████████████│
│  ████┌─🔆─┐█████████████│  ← فتحة مضيئة حول الزر
│  ████│ BTN │█████████████│
│  ████└─────┘█████████████│
└─────────────────────────┘
```

**التنفيذ**: عنصر `div` شفاف بنفس أبعاد الزر + `box-shadow: 0 0 0 9999px rgba(0,0,0,0.8)` + `border-radius` مطابق + توهج ذهبي داخلي. هذا يخلق "فتحة" طبيعية حول الزر بينما يعتّم كل شيء حوله.

### 2. موقع البطاقة الزجاجية (ديناميكي)
- **فوق الزر دائماً** — حساب `bottom` بناءً على موقع الزر + هامش 20px
- لن تحجب الزر أبداً لأنها ستكون في النصف العلوي من الشاشة
- خط ربط عمودي مضيء (خط ذهبي رفيع) يصل البطاقة بالزر

### 3. رسوم توضيحية SVG أنيقة لكل خطوة
بدل الإيموجي، رسوم SVG مخصصة:
- **يسار**: سهم منحني أنيق مع أثر حركة (motion trail)
- **يمين**: نفس السهم معكوس
- **إطلاق**: رمز crosshair دائري مع خطوط ليزر + صاروخ صغير
- **شقلبة**: شخصية دائرية تدور مع أثر دوران (arc trail)

كل أيقونة بحجم 48×48 بألوان متدرجة ذهبية مع توهج خفيف.

### 4. تأثيرات بصرية إضافية
- **نبض ضوئي** حول فتحة الزر (حلقة ذهبية تتمدد وتنكمش)
- **شرارات خفيفة** حول الفتحة (3-4 نقاط صغيرة تدور)
- **انتقال سلس** بين الخطوات — الفتحة تتحرك بـ `transition: all 0.4s ease` بدل القطع المفاجئ
- **زر "فهمت"** داخل البطاقة (ليس منفصلاً) لتجنب التشتت

### 5. تحسين التوزيع
- مؤشرات الخطوات (dots) في أعلى الشاشة بعيداً عن كل شيء
- البطاقة الزجاجية في منتصف الشاشة تقريباً (فوق خط الأزرار)
- الفتحة الضوئية حول الزر في الأسفل
- خط ربط ذهبي بينهما

### 6. هيكل HTML الجديد للطبقة
```text
<div overlay>                    ← يلتقط الضغطات
  <div spotlight-cutout>         ← فتحة ضوئية (box-shadow cutout)
    <div pulse-ring />           ← نبض ذهبي حول الفتحة
  </div>
  <div connecting-line />        ← خط ذهبي عمودي
  <div glass-card>               ← بطاقة الشرح
    <div step-dots />            ← مؤشرات الخطوات
    <svg icon />                 ← رسم توضيحي SVG
    <h3 title />                 ← العنوان العربي
    <p subtitle />               ← الشرح المفصل
    <button "فهمت" />            ← زر التقدم
  </div>
</div>
```
