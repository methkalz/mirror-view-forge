

# نظام الموجات + استراحة بين الموجات + دراجة OTLOP + بطاقات ترقية

## الفكرة العامة

تحويل اللعبة من تصعيد مستمر إلى **نظام موجات** كل 60-70 ثانية. بين كل موجتين: استراحة 10 ثوانٍ تتضمن دراجة نارية ديليفري OTLOP تسلم قنينة ماء + 3 بطاقات ترقية يختار اللاعب واحدة منها.

---

## 1. نظام الموجات (Wave System)

### المنطق
- كل **65 ثانية** (±5 عشوائي) تنتهي الموجة الحالية
- عند انتهاء الموجة:
  1. يتوقف إنتاج تهديدات جديدة فوراً
  2. الصواريخ والشظايا المتبقية في السماء تسقط وتنفجر بشكل طبيعي (لا تختفي فجأة)
  3. الطائرات تغادر الشاشة بسرعة
- بعد سقوط آخر تهديد: تبدأ فترة الاستراحة (10 ثوانٍ)

### حقول جديدة في `GameData`
```text
waveNumber: number           // رقم الموجة الحالية (1, 2, 3...)
wavePhase: 'active' | 'clearing' | 'rest' | 'cards'
waveTimer: number            // مؤقت الموجة (60-70ث)
restTimer: number            // مؤقت الاستراحة (10ث)
```

## 2. دراجة نارية ديليفري OTLOP

### الكيان الجديد — `DeliveryBike`
```text
interface DeliveryBike {
  active: boolean;
  pos: Vec2;
  speed: number;
  facingRight: boolean;
  phase: 'entering' | 'dropping' | 'leaving';
  dropX: number;          // مكان إسقاط القنينة
  dropped: boolean;
  wheelAnim: number;      // دوران العجلات
}
```

### السلوك
- تدخل من يمين أو يسار الشاشة بسرعة عشوائية (200-350 px/s)
- تسير على **نفس مستوى الأرض** (groundY) — الإطارات تلمس الأرض
- تتباطأ تدريجياً عند نقطة الإسقاط (منطقة وسطية 20%-80% من عرض الشاشة)
- تترك قنينة ماء على الأرض ثم تتسارع وتغادر
- حجم متناسب: عرض ~50px، ارتفاع ~35px (نسبة معقولة مع اللاعب ~22px)
- صندوق برتقالي خلفي مكتوب عليه "OTLOP" — النص لا ينعكس أبداً

### قنينة الماء (Water Bottle)
- power-up جديد `type: 'water'` — يضيف +20 HP
- تبقى على الأرض حتى يلتقطها اللاعب (لا تختفي بمؤقت أثناء الاستراحة)

### التصميم البصري
- جسم الدراجة: مستطيل رمادي داكن مع تفاصيل
- عجلتان دائريتان سوداوتان تدوران بسرعة الحركة
- سائق مبسط (شكل بشري صغير)
- صندوق برتقالي خلفي بنص "OTLOP" أبيض
- غبار خفيف من الإطارات أثناء الحركة

## 3. بطاقات الترقية (Upgrade Cards)

### المنطق
- تظهر أثناء فترة الاستراحة بعد مرور الدراجة (~3 ثوانٍ من بداية الاستراحة)
- 3 بطاقات عشوائية من مجموعة ~8 ترقيات
- اللاعب يختار واحدة بالنقر/اللمس
- التأثير دائم لبقية اللعبة

### الترقيات المتاحة (Pool)
| الترقية | التأثير | الأيقونة |
|---------|---------|----------|
| صندوق ذخيرة+ | سعة الذخيرة القصوى تصبح 40 بدلاً من 30 | 🔫 |
| صحة محسّنة | الحد الأقصى للصحة يصبح 130 | ❤ |
| سرعة حركة+ | سرعة اللاعب +20% | 🏃 |
| تباطؤ مطوّل | مدة Slow-Mo تصبح 7 ثوانٍ | ⏳ |
| دحرجة سريعة | Dash Cooldown ينخفض لـ 0.5ث | 💨 |
| درع ممتد | مدة الدرع تصبح 12ث بدلاً من 8ث | 🛡 |
| جذب مغناطيسي | نطاق التقاط العناصر +50% | 🧲 |
| ضربة قوية | ضرر الرصاصة +1 | 💥 |

### التصميم البصري للبطاقات
- 3 بطاقات بعرض ~100px وارتفاع ~140px
- خلفية متدرجة داكنة مع حدود ذهبية
- أيقونة كبيرة في الأعلى
- اسم الترقية بخط واضح
- وصف قصير بخط صغير
- تأثير توهج عند التحويم/اللمس
- عند الاختيار: البطاقة تكبر ثم تتلاشى + مؤثر بصري

### التفاعل
- في `SkyfallGame.tsx`: إضافة حالة React لإظهار البطاقات كطبقة HTML فوق الـ Canvas
- أو رسمها داخل الـ Canvas مع معالجة اللمس/النقر على مناطقها

---

## 4. تدفق اللعبة المحدث

```text
Wave 1 (0-65s) → Clearing → Rest (10s) → Cards → Wave 2 (65-130s) → ...

خلال Rest:
 - الثانية 0-2: هدوء
 - الثانية 2-5: دراجة OTLOP تدخل وتسلم قنينة ماء
 - الثانية 4-8: بطاقات الترقية تظهر
 - الثانية 8-10: اختفاء البطاقات + تحذير الموجة التالية
```

## التفاصيل التقنية

### `src/game/types.ts`
- إضافة `DeliveryBike` interface
- إضافة `'water'` إلى `PowerUpType`
- إضافة حقول الموجات إلى `GameData`: `waveNumber`, `wavePhase`, `waveTimer`, `restTimer`, `deliveryBike`, `upgradeCards`, `selectedUpgrade`
- إضافة `UpgradeCard` interface: `{ id, name, description, icon, effect }`
- إضافة حقول الترقيات الدائمة إلى `Player`: `maxAmmo`, `speedMultiplier`, `slowMoDuration`, `shieldDuration`, `pickupRange`, `bulletDamage`

### `src/game/engine.ts`
- دالة `checkWaveEnd(g)`: فحص انتهاء الموجة بعد 60-70ث
- دالة `startClearing(g)`: وقف الإنتاج + طرد الطائرات
- دالة `startRest(g)`: بدء الاستراحة + إنشاء الدراجة
- دالة `spawnDeliveryBike(g)`: إنشاء وتحريك الدراجة
- دالة `updateDeliveryBike(g, dt)`: فيزياء الدراجة (تباطؤ/تسارع)
- دالة `generateUpgradeCards(g)`: اختيار 3 ترقيات عشوائية
- دالة `applyUpgrade(g, cardId)`: تطبيق الترقية المختارة
- تعديل `update()`: إضافة منطق `wavePhase` قبل منطق الإنتاج
- تعديل منطق الإنتاج ليتوقف في phases غير 'active'

### `src/game/renderer.ts`
- دالة `renderDeliveryBike(ctx, g)`: رسم الدراجة بتفاصيل احترافية
- دالة `renderUpgradeCards(ctx, g)`: رسم البطاقات الثلاث داخل الـ Canvas
- دالة `renderWaveIndicator(ctx, g)`: مؤشر رقم الموجة في الـ HUD
- دالة `renderRestOverlay(ctx, g)`: تأثير بصري خفيف أثناء الاستراحة

### `src/components/SkyfallGame.tsx`
- معالجة نقر/لمس البطاقات: تحويل إحداثيات النقر لتحديد البطاقة المختارة
- أو إضافة طبقة HTML للبطاقات (أسهل للتفاعل)

### الملفات المتأثرة
1. **`src/game/types.ts`** — أنواع جديدة (DeliveryBike, UpgradeCard, حقول الموجات)
2. **`src/game/engine.ts`** — منطق الموجات + الدراجة + الترقيات
3. **`src/game/renderer.ts`** — رسم الدراجة + البطاقات + مؤشر الموجة
4. **`src/components/SkyfallGame.tsx`** — معالجة تفاعل البطاقات
