

# إصلاح الهوامش وتحسين معاينة الخلفيات في لوحة التحكم

## المشكلة الأولى: تأثير لوني على الهوامش
في وضع `blur-edge`، الهوامش تُرسم بنسخة ضبابية (blurred) من الصورة — هذا يجعلها تبدو مختلفة بصرياً عن الصورة الأصلية. المطلوب: الهوامش هي مجرد امتداد طبيعي للصورة بدون أي تأثير مختلف.

**الحل في `renderer.ts`:**
- وضع **Single**: الصورة تُمدد لتغطي `viewportW + margin` — الهوامش جزء من الصورة نفسها (صحيح حالياً)
- وضع **Blur Edge**: يُزال منطق البلور تماماً ويُستبدل بنفس منطق Single — الصورة تُمدد لتغطي المساحة الكاملة بدون أي filter
- وضع **Tiled**: يبقى كما هو (التبليط يغطي كل شيء)

بمعنى آخر: **Blur Edge يصبح مُلغى عملياً** لأن الهوامش يجب أن تكون امتداداً طبيعياً. أو نُبقي الخيار لكن نوضح أنه "تأثير جمالي اختياري" ونُصلح Single ليكون الافتراضي بدون أي تأثير.

## المشكلة الثانية: المعاينة سيئة
المعاينة الحالية (60px مستطيل صغير) لا تُظهر كيف ستبدو الخلفية فعلياً على هاتف اللاعب.

**الحل — معاينة بشكل هاتف حقيقي:**

```text
┌─────────────────────────────────────┐
│  📱 Preview                         │
│  ┌─────────────────────────────┐    │
│  │  ╔═══════════════════╗      │    │
│  │  ║                   ║      │    │
│  │  ║   VISIBLE AREA    ║      │    │
│  │  ║   (viewport)      ║      │    │
│  │  ║                   ║      │    │
│  │  ╚═══════════════════╝      │    │
│  │ ←margin→           ←margin→ │    │
│  └─────────────────────────────┘    │
│  Drag to simulate camera movement   │
└─────────────────────────────────────┘
```

- Canvas حقيقي (ليس مجرد `<img>`) بنسبة أبعاد هاتف (9:16 أو 9:19.5)
- إطار هاتف مرسوم حوله (notch علوي، زوايا مدورة)
- الصورة تُرسم بنفس المنطق الفعلي (`drawSingleImage` / `drawTiledImage`)
- خط متقطع يوضح حدود الـ viewport الفعلي
- المساحة خارج الـ viewport (الهوامش) تظهر بشفافية خفيفة مع label "MARGIN"
- **سحب أفقي (drag)** لمحاكاة حركة الكاميرا يميناً/يساراً — يُظهر كيف تتحرك الخلفية مع اللاعب

## التغييرات

### 1. `src/game/renderer.ts`
- `drawBlurEdgeImage`: إزالة `ctx.filter = 'blur(25px)'` — تصبح مطابقة لـ `drawSingleImage` ولكن مع رسم الصورة بشكل يغطي الحواف بتمديد طبيعي (cover كامل بدون بلور)
- التأكد من أن الصورة في كل الأوضاع تغطي `viewportW + margin*2` لضمان عدم ظهور أي فراغ عند أقصى حركة للكاميرا

### 2. `src/pages/Admin.tsx` — معاينة احترافية
- استبدال المعاينة الصغيرة (60px) بـ **Canvas element** بارتفاع ~200px
- رسم إطار هاتف (rounded rect + notch)
- رسم الصورة داخل الـ Canvas بنفس خوارزمية `drawSingleImage` / `drawTiledImage`
- رسم حدود viewport بخط متقطع
- تظليل منطقة الهوامش مع label
- **Drag handler** على الـ Canvas: `onMouseDown/Move` و `onTouchStart/Move` لمحاكاة حركة الكاميرا
- تحديث فوري عند تغيير الـ margin أو display mode

### تفاصيل تقنية للمعاينة
- الـ Canvas يرسم الصورة بنسبة الهاتف الحقيقية (مثلاً 375×812)
- المقياس: `previewScale = canvasHeight / 812`
- عند السحب: `simulatedCamX` يتغير → الصورة تتحرك → المستخدم يرى فعلياً أين تنتهي الصورة
- overlay شفاف على منطقة الهوامش مع خطوط متقطعة
