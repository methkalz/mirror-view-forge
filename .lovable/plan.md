

# إضافة زر "متابعة" بعد انتهاء التحميل لتشغيل الموسيقى

## المشكلة
المتصفحات تمنع تشغيل الصوت بدون تفاعل مستخدم. حالياً شاشة التحميل تنتقل تلقائياً لشاشة الاسم بدون أي نقرة، فيبقى AudioContext معلّقاً.

## الحل
بدل الانتقال التلقائي عند 100%، يظهر زر "متابعة" (أو "ابدأ"). نقرة المستخدم على الزر تُعتبر تفاعلاً صالحاً فيُفعَّل AudioContext وتبدأ الموسيقى فوراً.

### 1. `src/components/GameLoader.tsx`
- عند `progress >= 100`: بدل بدء fadeOut تلقائياً، يظهر زر عربي أنيق (مثلاً "ابدأ المغامرة ⚔️") بتصميم متوافق مع الثيم الحالي
- عند الضغط على الزر: استدعاء `startMenuMusic()` ثم `onLoaded()`
- إضافة import لـ `startMenuMusic` من `@/game/audio`

### 2. `src/components/NameEntry.tsx`
- إزالة مستمعات التفاعل لبدء الموسيقى (useEffect السطور 41-61) بالكامل — لم تعد ضرورية لأن الموسيقى تبدأ من GameLoader
- إبقاء باقي الكود كما هو

### 3. لا تغيير على `src/game/audio.ts` أو `SkyfallGame.tsx`
- نظام الحماية (mutex + attemptId) يبقى كما هو
- `cancelMenuMusicStart()` + `stopMenuMusic()` عند بدء اللعب يبقى كما هو

## التدفق الجديد
```text
تحميل → شريط يصل 100% → يظهر زر "ابدأ المغامرة"
→ المستخدم ينقر → startMenuMusic() ✓ (تفاعل حقيقي)
→ الموسيقى تعمل + انتقال لشاشة الاسم
→ الموسيقى مستمرة طوال شاشة الاسم + شاشة Start
→ بدء اللعب → stopMenuMusic() ✓
```
