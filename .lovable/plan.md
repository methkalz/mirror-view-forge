

# نظام Boss + تحسينات بصرية وصوتية

## 1. نظام Boss — طائرة حربية عملاقة

### الفكرة
كل **4 دقائق** تظهر طائرة حربية كبيرة (Gunship) كعدو رئيسي. تدخل من جانب الشاشة مع تحذير سينمائي مسبق ("⚠️ GUNSHIP INCOMING!"). لها 3 مراحل هجوم:

- **المرحلة 1** (HP > 66%): إطلاق صواريخ متتابعة (3 صواريخ سريعة)
- **المرحلة 2** (HP 33-66%): قصف سجادي (سلسلة انفجارات أرضية متتابعة من اليسار لليمين)
- **المرحلة 3** (HP < 33%): إطلاق درونات صغيرة مرافقة + صواريخ

### مواصفات Boss
- حجم كبير (~80px)، صحة عالية (15-20 ضربة)، يتحرك ببطء عبر أعلى الشاشة
- عند التدمير: انفجار سينمائي ضخم متعدد المراحل + مكافأة نقاط كبيرة (+500) + إسقاط power-up مضمون
- مع كل ظهور يزداد قوة (صحة أكبر، هجمات أسرع)

### Types الجديدة (`types.ts`)
- إضافة `Boss` interface: `pos`, `vel`, `health`, `maxHealth`, `phase`, `attackTimer`, `attackPattern`, `entered`, `defeated`
- إضافة `boss: Boss | null` و `bossCount: number` في `GameData`

## 2. تحسينات بصرية

### تأثيرات الطقس (`renderer.ts`)
- **مطر خفيف** يبدأ بعد الدقيقة 2 ويزداد كثافة مع الصعوبة (خطوط مائلة شفافة)
- **برق** عشوائي كل 15-30 ثانية بعد الدقيقة 3 (وميض أبيض سريع للشاشة بالكامل)
- **رياح** تؤثر على اتجاه المطر والدخان

### إضاءة محسّنة
- تأثير إضاءة ديناميكي حول الانفجارات (دائرة إضاءة برتقالية مؤقتة تنير المباني المحيطة)
- إضاءة أمامية للاعب (منطقة دائرية خافتة حوله)

## 3. تحسينات صوتية (`audio.ts`)

### موسيقى خلفية تصاعدية
- نبض قلب منخفض يتسارع مع ارتفاع الصعوبة (باستخدام OscillatorNode)
- طبقة طبول خفيفة تبدأ بعد الدقيقة 1

### مؤثرات جديدة
- صوت رعد مصاحب للبرق
- صوت صفارة إنذار عند ظهور Boss
- صوت انفجار Boss مختلف (أعمق وأطول)

## التغييرات التقنية

| الملف | التغييرات |
|-------|----------|
| `types.ts` | إضافة `Boss` interface + حقول `boss`, `bossCount` في `GameData` |
| `engine.ts` | منطق spawn/update/attack للـ Boss، تصعيد الطقس مع الوقت |
| `renderer.ts` | رسم Boss كطائرة حربية، تأثيرات مطر/برق/إضاءة ديناميكية |
| `audio.ts` | موسيقى خلفية تصاعدية، صوت رعد، صفارة Boss |
