

# إضافة مجموعة أصوات مرافقة (Ambient Companions) مع تحكم بالفاصل الزمني ونمط التشغيل

## الفكرة
إضافة فئة جديدة "أصوات مرافقة" في لوحة التحكم الصوتي، تتيح رفع مجموعة ملفات صوتية تُشغَّل تلقائياً أثناء اللعب كل N ثانية، إما عشوائياً أو بالترتيب.

## الوضع الحالي
- النظام الحالي يدعم بالفعل `intervalSeconds` و `playMode` (random/sequential/loop/single) لكل صوت
- يوجد نظام `startPeriodicAmbient()` يقرأ الأصوات التي لديها `intervalSeconds > 0` ويشغلها دورياً
- **المشكلة**: لا توجد فئة مخصصة في لوحة التحكم لإدارة هذا النوع بسهولة، والـ UI لا يُبرز خيار الفاصل الزمني بشكل واضح

## الحل

### 1. إضافة فئة جديدة في لوحة التحكم (`src/pages/Admin.tsx`)
- إضافة `ambientFX` في `CATEGORY_META`:
  ```
  ambientFX: { icon: '🎵', label: 'Ambient FX', labelAr: 'أصوات مرافقة', color: '#06b6d4' }
  ```
- عند إنشاء صوت جديد في هذه الفئة، يتم تلقائياً تعيين `intervalSeconds = 15` كقيمة افتراضية

### 2. إبراز التحكم بالفاصل الزمني ونمط التشغيل (`src/pages/Admin.tsx`)
- في عنصر كل صوت داخل فئة `ambientFX`، عرض slider واضح للفاصل الزمني (5-120 ثانية)
- عرض أزرار نمط التشغيل (عشوائي / بالترتيب) بشكل بارز
- هذه الخيارات موجودة أصلاً لكن ستكون أوضح وأبرز لهذه الفئة

### 3. التأكد من عمل المحرك (`src/game/audio.ts`)
- `startPeriodicAmbient()` يعمل بالفعل مع أي صوت لديه `intervalSeconds > 0`
- التأكد أن أصوات فئة `ambientFX` تُلتقط تلقائياً عند بدء اللعبة
- إضافة دعم الـ Realtime: عند تغيير إعدادات هذه الفئة، إعادة تشغيل الـ timers

### الملفات
1. **`src/pages/Admin.tsx`**: إضافة فئة `ambientFX` + إبراز slider الفاصل الزمني ونمط التشغيل
2. **`src/game/audio.ts`**: إعادة تشغيل periodic timers عند `reloadAudioSettings()` + التأكد من دعم الفئة الجديدة
