

# إضافة تأثيرات صوتية مختلفة لكل مستوى إطلاق

## الوضع الحالي
لا يوجد أي صوت عند الإطلاق حالياً. الإطلاق يتم في `engine.ts` سطر ~589 بدون استدعاء أي دالة صوتية.

## التغييرات

### 1. `src/game/audio.ts` — إضافة 3 دوال صوتية
- **`sfxShoot1()`** — طلقة مفردة: نبضة قصيرة حادة (800Hz, 0.06s, square) + ضوضاء خفيفة
- **`sfxShoot2()`** — طلقة مزدوجة: نبضتان سريعتان (900Hz + 700Hz) + ضوضاء أعلى + صدى خفيف
- **`sfxShoot3()`** — طلقة ثلاثية: ثلاث نبضات متتالية (1000Hz → 800Hz → 600Hz) + ضوضاء كثيفة + أكثر عمقاً

### 2. `src/game/engine.ts` — استدعاء الصوت عند الإطلاق
- سطر ~589 بعد `input.shoot = false`: استدعاء الدالة المناسبة حسب `g.bulletLevel`:
  - Level 1 → `sfxShoot1()`
  - Level 2 → `sfxShoot2()`
  - Level 3 → `sfxShoot3()`

### الملفات المتأثرة
1. **`src/game/audio.ts`** — 3 دوال جديدة
2. **`src/game/engine.ts`** — استدعاء واحد عند الإطلاق
