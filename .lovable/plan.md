

# تحسين بطاقات الترقية — تصميم أكبر وأوضح وأكثر احترافية

## المشكلة الحالية
- البطاقات صغيرة جداً (100×140px) على شاشة موبايل 430px
- النصوص غير مقروءة (8-10px monospace)
- التصميم مزدحم بمعلومات كثيرة في مساحة ضيقة
- لا يوجد تفاعل بصري واضح عند اللمس

## التغييرات — `src/game/renderer.ts` فقط

### 1. تكبير البطاقات بشكل كبير
- حجم جديد: **130×185px** (بدلاً من 100×140)
- gap: **12px** (ضيق قليلاً ليتسع الثلاث بطاقات)
- موقع عمودي: 30% من الشاشة (أعلى قليلاً لمساحة أكبر)

### 2. تصميم Elegant Minimalist
- خلفية: gradient داكن نظيف مع شفافية 97%
- حدود: خط واحد رفيع (1.5px) بلون البطاقة
- بدون glow مبالغ — فقط ظل خفيف ناعم
- زوايا مستديرة أكبر (14px)

### 3. تخطيط محتوى البطاقة الجديد
```text
┌──────────────────┐
│                  │
│     🔫 (36px)    │  ← أيقونة كبيرة واضحة
│                  │
│   MAX AMMO+      │  ← اسم 13px bold
│   سعة ذخيرة+     │  ← عربي 11px
│                  │
│  30 → 40 rounds  │  ← وصف 10px
│                  │
│   ─── TAP ───    │  ← تلميح 9px نابض
└──────────────────┘
```

### 4. تحسين العنوان
- "CHOOSE UPGRADE" بحجم **20px** bold
- سطر فرعي عربي "اختر ترقية" بحجم **13px**

### 5. شريط الوقت
- أعرض (4px بدلاً من 3px)
- زوايا مستديرة
- يتناسب مع العرض الجديد للبطاقات

### 6. تأثير تحديد (Selected card)
- البطاقة المختارة تكبر قليلاً (scale 1.05) مع حدود أسطع
