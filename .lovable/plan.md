# شريحة تعليم الأزرار التفاعلية — قبل بدء الموجة الأولى

## الفكرة

بعد انتهاء المقدمة السينمائية وقبل بدء اللعب فعلياً، تظهر طبقة تعتيم فوق الشاشة مع إضاءة على زر واحد في كل مرة + شرح عربي في وسط الشاشة. اللاعب يضغط في أي مكان أو على زر "فهمت" للانتقال للزر التالي.

## التسلسل (4 خطوات)


| الخطوة | الزر المضاء  | النص العربي                                                    |
| ------ | ------------ | -------------------------------------------------------------- |
| 1      | ‹ (يسار)     | "تحرّك لليسار"                                                 |
| 2      | › (يمين)     | "تحرّك لليمين"                                                 |
| 3      | FIRE (إطلاق) | "اطلق مضادات أرضية - يمكنك اعتراض الصواريخ والشظايا والطائرات" |
| 4      | ROLL (شقلب)  | "شَقلِب - تفادى الخطر بدحرجة سريعة"                            |


بعد الخطوة 4 → يبدأ اللعب فعلياً (الموجة 1).

## التنفيذ — ملف واحد: `src/components/SkyfallGame.tsx`

### 1. إضافة حالة التعليم

```typescript
const [controlTutorial, setControlTutorial] = useState<number>(-1); // -1 = غير نشط, 0-3 = الخطوة الحالية
```

### 2. تفعيل التعليم عند بدء اللعب

عند `setShowButtons(true)` (سطر 231)، بدل إظهار الأزرار مباشرة:

- ضبط `controlTutorial = 0` لبدء التعليم
- إيقاف اللعبة مؤقتاً (عبر ref لمنع `update()` أثناء التعليم)

### 3. طبقة التعتيم التفاعلية (HTML Overlay)

عند `controlTutorial >= 0`، يُعرض:

- **خلفية سوداء شفافة** (`rgba(0,0,0,0.75)`) تغطي كل الشاشة ما عدا الزر المضاء
- **الزر المضاء**: يُرسم "فتحة" (cutout) حول موقع الزر الحالي باستخدام `box-shadow` ضخم على عنصر شفاف بنفس حجم وموقع الزر
- **نص الشرح**: في وسط الشاشة بخط Tajawal عربي + خلفية زجاجية (glass card)
- **زر "فهمت"**: أسفل النص مباشرة بنمط ذهبي

### 4. التنقل بين الخطوات

- الضغط على أي مكان على الطبقة أو زر "فهمت" → `controlTutorial++`
- عند `controlTutorial > 3` → إخفاء الطبقة + بدء اللعب الفعلي

### 5. إظهار الأزرار

- أثناء التعليم: كل الأزرار مرئية لكن **الزر الحالي فقط** له إضاءة وبروز (scale + glow)
- باقي الأزرار شبه شفافة (`opacity: 0.15`)

### 6. إيقاف اللعبة مؤقتاً

إضافة `pauseRef = useRef(false)` — يُضبط `true` أثناء التعليم، ويمنع استدعاء `update()` في حلقة اللعب. هذا يُجمّد اللعبة خلف التعتيم.
