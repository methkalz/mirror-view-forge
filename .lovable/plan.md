

# استبدال الخلفية بالصورة المرفقة مع الحفاظ على التأثيرات

## الفكرة
استبدال الخلفية المولّدة برمجياً (السماء + المباني + الأرض) بالصورة المرفقة، مع الحفاظ على جميع التأثيرات: تدرج الألوان الديناميكي مع الوقت، النجوم، الغيوم، تأثير الـ vignette، البرق، المطر، وميض الضرر، والـ slow-mo.

## التغييرات

### 1. نسخ الصورة إلى المشروع
- نسخ `user-uploads://IMG_7842.jpeg` → `src/assets/bg-city.jpeg`

### 2. `src/game/renderer.ts` — تحميل الصورة واستخدامها

**تحميل الصورة (أعلى الملف):**
- إنشاء `Image` object وتحميل الصورة
- متغير `bgLoaded` للتأكد من جاهزيتها

**استبدال `renderSky` + `renderCitySilhouette` + `renderGround`:**
- دالة جديدة `renderBackground` ترسم الصورة لتغطي المنطقة المرئية بالكامل (مع تكرار أفقي إن لزم لمنع الفراغات)
- فوق الصورة: رسم طبقة ملونة شبه شفافة تتغير مع الوقت (نفس `getSkyColors`) — هذا يحافظ على التدرج الديناميكي (ليلي → فجر → جحيم)
- الحفاظ على النجوم والغيوم فوق الطبقة اللونية

**في `render()`:**
- استبدال:
  ```
  renderSky(ctx, g);
  renderCitySilhouette(ctx, g);
  renderGround(ctx, g);
  ```
  بـ:
  ```
  renderBackground(ctx, g);
  ```

### 3. الحفاظ على كل التأثيرات الأخرى
- الـ vignette، البرق، المطر، الجسيمات، وميض الضرر — كلها تبقى كما هي بدون تغيير (مرسومة فوق الخلفية)

### ملخص
| العنصر | قبل | بعد |
|--------|------|------|
| السماء | تدرج لوني مولّد | صورة المدينة المرفقة |
| المباني | أشكال هندسية مولّدة | جزء من الصورة |
| الأرض | تدرج بني | جزء من الصورة (الرصيف) |
| التأثير الزمني | تغيير ألوان السماء | طبقة لونية شفافة فوق الصورة |
| النجوم/الغيوم | مرسومة فوق السماء | تبقى مرسومة فوق الصورة |
| Vignette/برق/مطر | فوق كل شيء | بدون تغيير |
