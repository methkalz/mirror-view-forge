

# إصلاح مشهد المقدمة — راكب واحد ينزل + دراجة محسّنة + عدم حجب الصندوق

## المشاكل الحالية

1. **ينزل راكبان**: أثناء `playerDismount`، الكود يرسم الراكب النازل داخل `renderMotorcycle` **ويرسم أيضاً** اللاعب العادي عبر `renderPlayer` (السطر 4081 يخفيه فقط أثناء `bikeEnter`/`bikeStop` لكن ليس أثناء `playerDismount`)
2. **الراكب يحجب صندوق OTLOP**: الراكب موضوع عند `x: -10` والصندوق يمتد من `x: -24` إلى `x: -8` — تداخل مباشر
3. **شكل الدراجة يحتاج تحسين**: الهيكل مسطح والتفاصيل قليلة

## الحل

### 1. إصلاح بق الراكبَين (`renderer.ts` سطر 4081)
```typescript
// قبل (خاطئ):
const hidePlayer = g.state === 'intro' && (g.introPhase === 'bikeEnter' || g.introPhase === 'bikeStop');

// بعد (صحيح):
const hidePlayer = g.state === 'intro' && g.introPhase !== 'bikeLeave' && g.introPhase !== 'done';
```
هذا يخفي `renderPlayer` طوال مراحل `bikeEnter` + `bikeStop` + `playerDismount` — فيظهر راكب واحد فقط (المرسوم داخل `renderMotorcycle`)

### 2. نقل الراكب أمام الصندوق (`renderer.ts` — `renderMotorcycle`)
- تغيير موقع الراكب من `x: -10` إلى `x: 6` (أمام السائق، بين السائق والمقود)
- أو الأفضل: وضعه عند `x: 8, y: -17` ليجلس **أمام** صندوق التوصيل وخلف السائق مباشرة
- ترتيب الرسم: الصندوق أولاً ← الراكب ← السائق (z-order صحيح)

### 3. تحسين شكل الدراجة النارية
- **هيكل أكثر انحناءً**: استبدال المسار الحالي المكون من `quadraticCurveTo` واحد بمنحنيات `bezierCurveTo` متعددة لجسم انسيابي حقيقي
- **مقعد ممدود واقعي**: مقعد طويل بوسادة مزدوجة (سائق + راكب) بتدرج لوني
- **لوحة جانبية**: إضافة panel جانبي ملون بين المحرك والمقعد
- **مساند أقدام**: footpegs مرئية عند مواقع الأقدام الفعلية
- **تحسين المصباح الأمامي**: شكل بيضاوي مع انعكاس ضوئي بدلاً من دائرة بسيطة
- **سلسلة/ناقل حركة**: خط رفيع بين المحرك والعجلة الخلفية

### 4. تحسين حركة النزول (`renderer.ts` — قسم dismounting)
- المرحلة 1: الراكب يرفع رجله للخلف (فوق المقعد) — ليس للأمام
- المرحلة 2: ينزلق جانبياً عن المقعد مع انحناء طبيعي للجسم
- المرحلة 3: يلمس الأرض ويستقيم — مع تأثير غبار خفيف عند اللمس
- بعد النزول الكامل (`dp >= 1`): إيقاف رسم الشخصية داخل `renderMotorcycle` والاعتماد على `renderPlayer` فقط

### 5. ضبط الانتقال من النزول للعب (`engine.ts`)
- عند نهاية `playerDismount`: تعيين `g.player.pos` بدقة لموقع النزول النهائي حتى لا يحدث "قفزة" عند التبديل من الشخصية المرسومة داخل الدراجة للشخصية المستقلة

## الملفات المتأثرة
1. **`src/game/renderer.ts`** — إصلاح hidePlayer + نقل موقع الراكب + تحسين الدراجة + تحسين النزول
2. **`src/game/engine.ts`** — ضبط موقع اللاعب عند نهاية النزول
