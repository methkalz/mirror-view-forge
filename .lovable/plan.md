## 2. نقل زر الإطلاق بجانب السهم الأيمن (`SkyfallGame.tsx`)

التخطيط الحالي:
```text
           [ FIRE ]
  [  ‹  ]          [  ›  ]         [ ROLL ]
```

التخطيط الجديد — زر الإطلاق يمين السهم الأيمن مباشرة:
```text
  [  ‹  ]     [  ›  ]  [ 🔫 ]     [ ROLL ]
```

- تغيير موقع FIRE: `left: 136, bottom: 170` → `left: 220, bottom: 95`
- ارتفاع متساوي مع الأسهم: `height: 56` بدل `52`
- هذا يجعل الإبهام الأيمن يصل للإطلاق والتوجيه بسهولة
