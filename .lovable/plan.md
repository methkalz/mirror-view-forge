

# إعادة تصميم شريحة البدء — تصميم سينمائي احترافي

## الرؤية

بدل التصميم الحالي البسيط (عنوان + زر + اسم مطور)، سنبني شريحة بدء **سينمائية** تبهر اللاعب وتجعله متحمساً للبدء.

## التصميم الجديد

```text
┌──────────────────────────────┐
│                              │
│    ✦ خطوط ضوئية متقاطعة ✦    │  ← أشعة ضوئية رفيعة تدور ببطء
│                              │
│      ╔══════════════════╗    │
│      ║   S K Y F A L L  ║    │  ← حروف متباعدة بتأثير tracking
│      ║    ─── ◆ ───     ║    │     واسع + metallic gradient
│      ║    SURVIVAL      ║    │
│      ╚══════════════════╝    │
│                              │
│     ❝ هل أنت مستعد؟ ❞       │  ← نص عائم بتأثير typewriter
│                              │
│   ┌─────────────────────┐    │
│   │  ▶  يلا يلا         │    │  ← زر بتأثير scan-line + نبض
│   └─────────────────────┘    │     بأسلوب HUD عسكري
│                              │
│     ⟐ أفضل نتيجة: 420 ⟐    │  ← بطاقة glass صغيرة
│                              │
│                              │
│    تطوير: مثقال زيدان        │  ← أسفل الشاشة بأناقة
│    ─────── ◆ ───────         │
└──────────────────────────────┘
```

## التغييرات في `src/game/renderer.ts` — دالة `renderTutorialSlide3`

### 1. أشعة ضوئية خلفية (Light Rays)
- 4-6 خطوط رفيعة بيضاء/ذهبية شبه شفافة تنطلق من المركز
- تدور ببطء (`t * 0.3`) مع تلاشي تدريجي للأطراف
- تضيف عمقاً سينمائياً دون إزعاج

### 2. عنوان SKYFALL بتأثير Tracking واسع
- حروف متباعدة: `S K Y F A L L` بدل `SKYFALL` (letter-spacing يدوي)
- حجم 48px مع metallic gradient محسّن
- توهج خارجي مزدوج (ذهبي + أبيض خفيف)
- حركة "تنفس" خفيفة في الحجم (`scale: 1 + sin(t) * 0.02`)

### 3. تأثير Typewriter لـ "هل أنت مستعد؟"
- النص يظهر حرفاً حرفاً عند أول دخول للشريحة
- بعد الاكتمال: وميض مؤشر كتابة `|` لمدة ثانية ثم يختفي
- الأحرف المعروضة = `text.slice(0, Math.min(text.length, Math.floor(elapsed * 8)))`

### 4. زر "يلا يلا" بأسلوب HUD عسكري
- زوايا مشطوفة (beveled) بدل مستديرة — يتوافق مع ذاكرة `button-styling-standards`
- خط مسح ضوئي (scan line) أفقي يتحرك من أعلى لأسفل داخل الزر
- تدرج أحمر عميق بدل الذهبي (عسكري أكثر)
- رمز `▶` صغير بجانب النص

### 5. بطاقة أفضل نتيجة (Glass Card)
- بطاقة glass صغيرة أنيقة بدل نص عادي
- أيقونة كأس `🏆` (نص) + الرقم بخط monospace ذهبي
- تُعرض فقط إذا `highScore > 0`

### 6. اسم المطور — تصميم signature
- `"مثقال زيدان"` بخط أكبر قليلاً (16px) مع `"تطوير"` فوقه بخط صغير (11px)
- خط فاصل ذهبي رفيع تحته مع ماسة صغيرة
- موقع ثابت أسفل الشاشة (`h * 0.92`)
