

# تحسين شخصية اللاعب — UI/UX

## الوضع الحالي
الشخصية مرسومة إجرائياً (procedural) بأشكال بسيطة: رأس دائري، جسم مستطيل، أرجل وأذرع كخطوط. التفاصيل محدودة — عين واحدة، خوذة بسيطة، بدون تعبيرات أو تفاصيل ملابس غنية.

## التحسينات المقترحة

### 1. تحسين الرأس والوجه
- إضافة **عين ثانية** (تظهر فقط عند النظر للكاميرا أو idle)
- إضافة **حاجبين** يتغيران حسب الحالة (عادي / غاضب عند الإصابة)
- تحسين الخوذة بإضافة **حزام ذقن** رفيع و**شعار** صغير (خط أمامي)

### 2. تحسين الجسم والملابس
- إضافة **ياقة** أوضح وتفاصيل **جيوب** على الصدر
- إضافة **حزام وسط** بين القميص والبنطلون
- تحسين تدرج لون القميص ليبدو أكثر واقعية

### 3. تحسين الأطراف
- إضافة **مفصل ركبة** في الأرجل (ثني واقعي أثناء المشي)
- تحسين حركة الأذرع مع **مفصل كوع**
- تكبير الحذاء قليلاً مع إضافة **نعل** ملون

### 4. تأثيرات بصرية حسب الحالة
- **Idle**: تنفس خفيف (حركة الصدر صعوداً ونزولاً)
- **Hit**: اهتزاز سريع (shake) + وميض أحمر (موجود) + تعبير وجه ألم
- **Roll**: أثر غبار خلف الشخصية أثناء الدحرجة
- **Walk**: حركة شعر/خوذة خفيفة مع الخطوات

### 5. تحسين HUD المرتبط بالشخصية
- إضافة **مؤشر صحة صغير** فوق رأس الشخصية مباشرة (شريط رفيع)
- توهج خفيف حول الشخصية يتغير لونه حسب الصحة (أخضر → أصفر → أحمر)
